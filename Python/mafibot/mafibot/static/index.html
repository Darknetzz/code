        Dashboard access token

        Optional shared secret that protects the dashboard API (start/stop bot, profiles, credentials). This is not your Mafiaspillet username or password.

        On the server, set the environment variable MAFIBOT_UI_TOKEN before running mafibot.py ui. Enter the same value below and click Save — it is kept only in this browser tab and sent on API calls (X-Mafibot-Token) and the live log WebSocket (?token=).

        Leave empty when you only open the dashboard at 127.0.0.1 (default). Use a long random token if you bind to another host or expose port 8766 on your network.
