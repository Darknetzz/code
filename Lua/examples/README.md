# Lua Examples

Quick examples to learn Lua. Run any example with an installed Lua interpreter:

```sh
lua filename.lua
```

Files added:
- `hello.lua` — Hello world
- `variables.lua` — basic variable types
- `control_flow.lua` — if/for/while examples
- `functions.lua` — functions and varargs
- `tables.lua` — arrays and dictionaries
- `metatables.lua` — simple metatable example
- `module_example.lua` — a small module
- `require_example.lua` — using the module
- `io_and_file.lua` — basic file I/O

Files are intentionally small and commented for learning.
